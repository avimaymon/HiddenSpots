# Field checklist (1–2 weeks)

Use this after shipping habit/growth/ops. Mark items while actually hiking.

## Day 0 (desk)

- [ ] Install PWA on phone home screen
- [ ] Confirm Google Drive backup connected (Settings)
- [ ] Import one My Maps layer (or skip if none)
- [ ] Share one collection to a hiking partner (WhatsApp)
- [ ] Set `ERROR_WEBHOOK_URL` on Vercel if you want Slack/Discord alerts

## In the field

- [ ] Add a spot with weak/no signal → comes back online and syncs
- [ ] Offline banner shows pending count; retry works if a sync fails
- [ ] “I’m here” logs a visit; optional photo attaches
- [ ] Go mode: ETA readable, auto-arrive ~80m, GPS pauses when phone locked/backgrounded
- [ ] Nearby sort on locations list feels right
- [ ] Hebrew empty states / search still make sense outdoors (sun theme)

## After trip

- [ ] Dashboard “This week” counts match what you did
- [ ] Collection share still opens for partner
- [ ] Drive dry-run restore (Settings) once
- [ ] Note friction in Feedback (in-app) — one sentence each

## Kill / keep

- Keep: anything you used without thinking
- Kill/hide: chrome you never opened outdoors
